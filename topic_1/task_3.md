# Техническое задание

## на закупку компьютерного и сетевого оборудования для образовательного учреждения СПО

### 1. Общие сведения

**Наименование закупки:**
Поставка компьютерного и сетевого оборудования для оснащения компьютерного кабинета структурного подразделения образовательного учреждения среднего профессионального образования.

**Заказчик:**
Образовательное учреждение среднего профессионального образования.

**Место поставки:**
Здание образовательного учреждения, компьютерный кабинет.

**Цель закупки:**
Оснащение компьютерного кабинета современным оборудованием для проведения занятий по информатике, информационным технологиям, программированию и профессиональным дисциплинам.

Оборудование должно обеспечивать возможность работы с офисными приложениями, образовательными платформами, средами программирования, графическими редакторами и другим программным обеспечением, используемым в образовательном процессе.


# 2. Нормативные требования

При подготовке и исполнении закупки необходимо руководствоваться действующим законодательством Российской Федерации.

Основным нормативным документом является Федеральный закон от 05.04.2013 № 44-ФЗ «О контрактной системе в сфере закупок товаров, работ, услуг для обеспечения государственных и муниципальных нужд».

В соответствии со статьёй 33 44-ФЗ описание объекта закупки должно содержать функциональные, технические и качественные характеристики товара, а также при необходимости эксплуатационные характеристики. Показатели должны позволять определить соответствие предлагаемого товара требованиям заказчика.

При составлении характеристик также необходимо учитывать применимые технические регламенты, документы национальной системы стандартизации и сведения КТРУ.

При наличии соответствующей позиции КТРУ характеристики, предусмотренные для неё, учитываются при описании объекта закупки.

# 4. Технические требования к персональному компьютеру

Каждый персональный компьютер должен соответствовать следующим требованиям:

| Характеристика         | Требование                                   |
| ---------------------- | -------------------------------------------- |
| Назначение             | Для использования в образовательном процессе |
| Процессор              | Не менее 6 вычислительных ядер               |
| Оперативная память     | Не менее 16 ГБ                               |
| Тип оперативной памяти | DDR4 или более современный стандарт          |
| Накопитель             | SSD                                          |
| Объём SSD              | Не менее 512 ГБ                              |
| Сетевой интерфейс      | Ethernet 1 Гбит/с или выше                   |
| Беспроводная сеть      | Wi-Fi, при необходимости                     |
| USB-порты              | Не менее 4                                   |
| Видеовыходы            | Не менее 1 цифрового видеовыхода             |
| Аудио                  | Встроенный аудиоконтроллер                   |
| Корпус                 | Предназначен для стационарного использования |
| Состояние              | Новое, ранее не использовавшееся             |
| Гарантия               | Не менее 12 месяцев                          |

Компьютер должен обеспечивать одновременную работу офисных приложений, браузера, среды программирования и другого программного обеспечения, необходимого для образовательного процесса.

В соответствии с 44-ФЗ поставляемый товар должен быть новым, если иное не предусмотрено описанием объекта закупки.


# 5. Требования к монитору

Каждый монитор должен соответствовать следующим требованиям:

| Характеристика      | Требование                               |
| ------------------- | ---------------------------------------- |
| Тип                 | ЖК-монитор                               |
| Диагональ           | Не менее 23,8 дюйма                      |
| Разрешение          | Не менее 1920 × 1080 пикселей            |
| Соотношение сторон  | 16:9                                     |
| Частота обновления  | Не менее 60 Гц                           |
| Интерфейс           | HDMI или DisplayPort                     |
| Регулировка наклона | Наличие                                  |
| Подключение         | Совместимость с поставляемым компьютером |
| Состояние           | Новое                                    |
| Гарантия            | Не менее 12 месяцев                      |

Монитор должен обеспечивать комфортное отображение текста, графической информации, программного кода и учебных материалов.


# 6. Требования к клавиатуре

Количество — **15 шт.**

Требования:

* полноразмерная клавиатура;
* стандартная раскладка;
* наличие русской и латинской раскладок;
* подключение через USB;
* совместимость с поставляемыми компьютерами;
* новое оборудование.


# 7. Требования к компьютерной мыши

Количество — **15 шт.**

Требования:

* оптический сенсор;
* подключение через USB;
* не менее двух основных кнопок;
* наличие колеса прокрутки;
* совместимость с поставляемыми компьютерами;
* новое оборудование.


# 8. Требования к коммутатору

Количество — **1 шт.**

Коммутатор предназначен для объединения компьютеров кабинета в локальную сеть.

| Характеристика                                    | Требование                         |
| ------------------------------------------------- | ---------------------------------- |
| Количество портов                                 | Не менее 24                        |
| Тип портов                                        | Ethernet                           |
| Скорость портов                                   | Не менее 1 Гбит/с                  |
| Автосогласование скорости                         | Наличие                            |
| Поддержка автоматического определения типа кабеля | Наличие                            |
| Управление                                        | Допускается управляемый коммутатор |
| Монтаж                                            | Настольный или стоечный            |
| Состояние                                         | Новое                              |
| Гарантия                                          | Не менее 12 месяцев                |

Коммутатор должен обеспечивать подключение всех 15 рабочих мест и иметь дополнительные порты для подключения другого сетевого оборудования.


# 9. Требования к маршрутизатору

Количество — **1 шт.**

Маршрутизатор должен обеспечивать подключение локальной сети компьютерного кабинета к существующей сетевой инфраструктуре образовательного учреждения.

Требования:

* наличие Ethernet-портов;
* поддержка IPv4;
* поддержка DHCP;
* возможность настройки локальной сети;
* возможность разграничения сетевого доступа;
* поддержка современных механизмов защиты сетевого соединения;
* возможность администрирования;
* наличие документации на русском языке;
* новое оборудование;
* гарантия не менее 12 месяцев.

Конкретные параметры маршрутизатора должны быть совместимы с действующей сетевой инфраструктурой образовательного учреждения.


# 10. Требования к источникам бесперебойного питания

Количество — **2 шт.**

ИБП предназначены для защиты сетевого оборудования и серверного/сетевого узла от кратковременных перебоев электропитания.

Требования:

* технология защиты оборудования от перепадов напряжения;
* наличие аккумуляторной батареи;
* автоматическое переключение на питание от аккумулятора;
* наличие защиты от перегрузки;
* наличие звуковой индикации состояния;
* возможность безопасного завершения работы подключённого оборудования;
* новое оборудование;
* гарантия не менее 12 месяцев.


# 11. Требования к сетевому фильтру

Количество — **5 шт.**

Требования:

* количество розеток — не менее 5;
* наличие защиты от перегрузки;
* наличие выключателя;
* кабель питания достаточной длины для размещения на рабочем месте;
* соответствие требованиям безопасности;
* новое оборудование.


# 12. Требования к программному обеспечению

Поставляемые компьютеры должны быть совместимы с программным обеспечением, используемым образовательным учреждением.

В частности, должна обеспечиваться возможность установки и использования:

* офисного программного обеспечения;
* веб-браузеров;
* сред разработки;
* языков программирования;
* образовательных приложений;
* средств просмотра документов;
* антивирусного и защитного программного обеспечения;
* другого программного обеспечения, необходимого для образовательного процесса.

При необходимости операционная система и иное программное обеспечение закупаются отдельными позициями с учётом требований заказчика и законодательства.


# 13. Требования к совместимости

Все поставляемые устройства должны быть совместимы между собой.

Компьютеры должны обеспечивать подключение поставляемых мониторов, клавиатур и мышей.

Сетевое оборудование должно обеспечивать совместную работу в локальной сети образовательного учреждения.

Поставщик обязан предоставить сведения о технических характеристиках оборудования, позволяющие проверить его совместимость с существующей инфраструктурой.


# 14. Требования к безопасности

Поставляемое оборудование должно соответствовать применимым требованиям технических регламентов и законодательства Российской Федерации.

Для оборудования, на которое распространяются обязательные требования о подтверждении соответствия, поставщик должен предоставить соответствующие документы.

Оборудование должно быть безопасным для эксплуатации в условиях образовательного учреждения.


# 15. Требования к информационной безопасности

Сетевое оборудование должно обеспечивать возможность безопасной эксплуатации локальной сети.

В зависимости от используемой инфраструктуры должны поддерживаться:

* разграничение доступа;
* настройка учётных записей администратора;
* изменение стандартных паролей;
* обновление программного обеспечения оборудования;
* журналирование событий, если такая функция предусмотрена;
* сегментация сети при необходимости;
* безопасное администрирование оборудования.

Требования к информационной безопасности должны соответствовать информационной инфраструктуре образовательного учреждения.


# 16. Требования к поставке

Поставщик обязан:

1. Поставить оборудование в полном объёме.
2. Поставить только новое оборудование.
3. Обеспечить целостность упаковки.
4. Предоставить эксплуатационную документацию.
5. Предоставить гарантийные документы.
6. При необходимости выполнить сборку и подключение оборудования.
7. Проверить работоспособность оборудования.
8. Передать заказчику оборудование и сопроводительные документы.


# 17. Монтаж и настройка

При необходимости в состав поставки должны входить:

* установка компьютеров на рабочие места;
* подключение мониторов;
* подключение клавиатур и мышей;
* подключение компьютеров к локальной сети;
* подключение коммутатора;
* подключение маршрутизатора;
* базовая настройка сетевого оборудования;
* проверка работоспособности локальной сети.

Монтаж и настройка выполняются поставщиком без повреждения существующей инфраструктуры образовательного учреждения.


# 18. Требования к гарантии

Гарантийный срок на оборудование должен составлять **не менее 12 месяцев** с даты подписания документов о приёмке, если более длительный срок не установлен производителем.

На оборудование должна предоставляться гарантия производителя и/или поставщика в соответствии с требованиями законодательства и условиями закупки.

При закупке машин и оборудования заказчик устанавливает требования к гарантийному сроку и гарантийному обслуживанию в случаях, предусмотренных статьёй 33 44-ФЗ.

В течение гарантийного срока поставщик должен обеспечить устранение выявленных неисправностей либо замену неисправного оборудования в соответствии с условиями контракта.


# 19. Требования к документации

Вместе с оборудованием поставщик предоставляет:

* техническую документацию;
* руководство пользователя;
* гарантийные документы;
* документы о подтверждении соответствия, если они предусмотрены законодательством;
* документы, необходимые для эксплуатации и обслуживания оборудования.


# 20. Порядок приёмки

Приёмка оборудования осуществляется представителем образовательного учреждения.

При приёмке проверяются:

1. соответствие количества поставленного оборудования ТЗ;
2. соответствие технических характеристик установленным требованиям;
3. отсутствие внешних повреждений;
4. комплектность;
5. наличие необходимой документации;
6. работоспособность оборудования;
7. возможность подключения оборудования к локальной сети;
8. соответствие поставленных устройств заявленным характеристикам.

При выявлении несоответствий заказчик действует в соответствии с условиями заключённого контракта и законодательством о контрактной системе.


# 21. Требования к участнику закупки

Требования к участникам закупки устанавливаются в соответствии с законодательством Российской Федерации.

При составлении описания объекта закупки не следует включать требования к производителю, квалификации участника, его деловой репутации и другим характеристикам участника, если возможность установления таких требований прямо не предусмотрена 44-ФЗ.

Техническое задание должно описывать прежде всего **сам закупаемый товар и требования к его характеристикам**, а не конкретного поставщика.


# 22. Обоснование выбора оборудования

Предлагаемый комплект оборудования рассчитан на организацию компьютерного кабинета на 15 рабочих мест.

Выбранные характеристики позволяют использовать компьютеры для:

* изучения информатики;
* программирования;
* работы с текстовыми документами;
* работы с электронными таблицами;
* создания презентаций;
* работы с образовательными платформами;
* работы с графическими материалами;
* выполнения практических и лабораторных работ.

Наличие 24-портового коммутатора позволяет подключить 15 компьютеров и сохранить резерв портов для дополнительного оборудования.

Использование SSD-накопителей и не менее 16 ГБ оперативной памяти обеспечивает возможность одновременной работы нескольких учебных приложений.

# Заключение

Разработанное техническое задание предназначено для закупки компьютерного и сетевого оборудования для структурного подразделения ОУ СПО.

При его составлении учитываются функциональные и технические потребности образовательного учреждения, требования к совместимости, безопасности, гарантии, поставке и приёмке оборудования.

В соответствии со статьёй 33 Федерального закона № 44-ФЗ характеристики закупаемого оборудования должны позволять определить соответствие предлагаемого товара требованиям заказчика. При этом описание не должно необоснованно ограничивать количество участников закупки.

Поэтому в данном ТЗ используются преимущественно **объективные и измеримые технические характеристики**, а не конкретные модели или торговые марки оборудования.
